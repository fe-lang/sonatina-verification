It's a common circumstance in type theory that one builds various type
families equipped with a native notion of composition, like the
Identity Type, Hom types in Category Theory formalization,
transitivity of partially ordered types, and so on. How can we write a
definition which captures all of these operations in dependent type
theory?

We can start by considering the type of the S-combinator in type
theory

> S : ∀ {u v w} {A : Type u} {B : A → Type v} {C : (x : A) → B x → Type w}
>   → ({x : A} (y : B x) → C x y) → (f : (x : A) → B x) (x : A) → C x (f x)
> S g f = λ x → g (f x)

From which we want to recover the abstract form of this composition
operation, which this particular function would thus serve as one
implemenation. Let's work backwards to see how we might reverse
engineer the correct type signature to describe the structure we
expect function composition to satisfy.

Let's now fix some more, which will serve as types for the S-combinator

> `A : Type',  `B : A → Type`, and `C : (a : A) → B a → Type`

Now that we have these, it's helpful to understand the term structure
we expect of our abstract operation, so lets unpack what happens to `S`
as we have functions to apply. Suppose we have terms of Pi-types

> `(f : (x : A) →  B x) (g : {x : A} (a : B x) → C x a)`

given a term `x : A`, we may form `g (f x) : C x (f x)` with our
composition operation. If we partially apply either f or g to S,
we end up with two functions:

> `S g : (h : (x : A) → B x) → (x : A) → C x (h x)`

> `λ h → S h f : ({x : A} (a : B x) → C x a) → (x : A) → C x (f x)`

or post and pre-composition. Notice that in post-composition, further
application leads to a function which is indexed on the input
function, i.e. from `(h : (x : A) → B x)` we may form a term `S g h :
(x : A) → C x (h x)`, and we should observe the resulting function
directly depends on the awaited input term in its type former itself.
This is not so for pre-composition, where the needed function (`g`) is
is not preserved in the final type.

This is analogous to the Cut rule from Sequent Calculus, which states
(cribbing from nlab) that when one has sequents of the form

> `Γ ⊢ B , Δ` and `Π , B ⊢ Λ`

one may form a new sequent, which I'll get to in a moment. For our
purposes, we may consider that the latter form above corresponds to
post-composition, and the former to pre-composition. Γ here plays the
role of our type A, while B is the predicate to be eliminated
in the course of composition. The resulting sequent has the form:

>  `Π , Γ ⊢ Λ , Δ`

The first sequent `Γ ⊢ B , Δ` states that from our context Γ, we may
infer B and its corollary co-context - this is the action of our `f`,
which takes an element `x` to `B x`, the corrolary of the consequent
`Δ`. Likewise, we have that given the context `Π` with some `B`, we
may derive the co-context Λ. This naturally corresponds to our `g`,
which takes an element `B a` for some `a : A` to `C x a`. What is
crucial to note is that the disjunction between `Γ` and `Π` consists
in how type `A` is universally quantified in the context `Γ`, while in
`Π` it fixes upon some `a : A`, which is necessary to form a term of
`B a`.  In order to compose the term `C x (f x)` it is thus necessary
to eliminate some `B x`, which is given to us by `f`. Therefore we
consider that it is the action of `g` that is 'cut' in composition
such that its only trace after the cut lies in the context `Π` from
which `g` originally arose.

In dependent type theory this is presented in the form of the
resulting predicate `C x (f x)`, which only preserves the form of the
specific `B x` generated by `f`, which thereafter leaves us with the
statement that we may form `C x (f x)` from any `x : A`.  Having fixed
the particular `f x : B x`, the capacity to form any `C x a` by the
action of `g` is now irrelevant for the purpose of following
deductions, and thus we only need preserve the deduction from which
`g` arose in the mute `Π`, i.e. as the antecedent of the final
deduction, the co-premise of `Γ`, from which the consequent `Λ, Δ` may
be deduced universally from any `A` inhabiting the context `Γ`. Hence
we are left with the form `∀ x → C x (f x)`, which thus has the shape:

>  `Π , Γ ⊢ Λ , Δ`

What is interesting about the type-theoretic presentation here is that
the overall process we describe may already be encoded precisely in
the sequent `Π , B ⊢ Λ`, containing the 'cut' term `B`. Indeed, if we
regard that `Π` contains some g, and `B` is a context containing some
`f`, the consequent may already be the presentation of some contexts
Φ and Ψ such that `Λ = Φ , ψ`, which had already been cut.

> `S g : (h : (x : A) → B x) → (x : A) → C x (h x)`
> `λ h → S h f : ({x : A} (a : B x) → C x a) → (x : A) → C x (f x)`

```
record Cut {u v w z}
  {A : Type u}
  (B : A → Type v) -- Γ ⊢ B , Δ
  (C : A → Type w) -- Π , B ⊢ Λ
  (D : ∀ x → B x → Type z) -- `Π , Γ ⊢ Λ , Δ`
  : Typeω
  where
  infixr 40 seq _∘_
  field
    seq : ∀ {x} (b : B x) (c : C x) → D x b
  {-# INLINE seq #-}

  _∘_ : ∀ {x} (c : C x) (b : B x) → D x b
  c ∘ b = seq b c
  {-# INLINE _∘_ #-}

open Cut ⦃ ... ⦄  renaming ( seq to _∙_ ) public

{-# DISPLAY Cut.seq _ = _∙_ #-}
{-# DISPLAY Cut._∘_ _ = _∘_ #-}

Hom-Cut : ∀ {u v} {Ob : Type u} (_~_ : Ob → Ob → Type v) → Typeω
Hom-Cut {Ob} _~_ = {y z : Ob} → Cut (λ (x : Ob) → x ~ y) (λ _ → y ~ z) λ x _ → x ~ z
